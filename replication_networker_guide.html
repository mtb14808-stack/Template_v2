Guida a ServerReplication & Networker

Sincronizzazione dati Server ↔ Client in Roblox Luau

1 Replica Globale (a tutti i giocatori)

SERVER BuildServer.luau

--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local ServerReplication = require(ReplicatedStorage.Packages.ServerReplication)

-- 1. Crea il Token univoco per identificare questo tipo di replica
local Token = ServerReplication.Server.Token("GameEvent")

local BuildServer = {}

function BuildServer:Init()
	-- 2. Crea la nuova Replica con i suoi dati iniziali
	local replica = ServerReplication.Server.New({
		Token = Token,
		Tags = {},
		Data = {
			Duration = 5,
			Name = "RADIOACTIVE",
		},
	})

	task.wait(3)
	
	-- 3. Invia e rende visibile la replica a TUTTI i client
	replica:Replicate()

	-- 4. Aspetta la durata dell'evento e poi distrugge la replica
	task.delay(replica.Data.Duration, function()
		warn("ENDED EVENT")
		replica:Destroy()
	end)
end

return BuildServer

CLIENT BuildClient.luau

--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local ServerReplication = require(ReplicatedStorage.Packages.ServerReplication)

local BuildClient = {}

function BuildClient:Init()
	-- 1. Ascolta l'arrivo di qualsiasi replica con Token "GameEvent"
	ServerReplication.Client.OnNew("GameEvent", function(Replica)
		warn("CONNECTED")

		-- 2. Legge i dati sincronizzati dal Server
		local EventName = Replica.Data.Name
		local Duration = Replica.Data.Duration
		warn("STARTED EVENT: " .. EventName .. " DURATION: " .. Duration)

		-- 3. Registra cosa fare quando il Server distruggerà la replica
		Replica.Maid:Add(function()
			warn("ENDED")
		end)
	end)

	-- 4. FONDAMENTALE: Richiede al server di inviare le repliche attive
	ServerReplication.Client.RequestData()
end

return BuildClient

Spiegazione riga per riga — Lato Server

ServerReplication.Server.Token("GameEvent")
Cosa fa: Crea un "timbro" o canale univoco.
Perché esiste: Assicura che nessun altro script sul server possa accidentalmente creare una replica con lo stesso identico nome duplicato mandando in confusione il client.
ServerReplication.Server.New({ Token, Tags, Data })
Cosa fa: Alloca e costruisce l'oggetto Replica nella memoria del server.
Token: Dice a quale canale registrato appartiene questa replica.
Tags = {}: Una tabella immutabile per identificatori (es. se fosse di un giocatore ci metteresti { UserId = player.UserId }). Essendo un evento globale per tutti, la lasciamo vuota.
Data = {...}: È la tabella vera e propria contenente i dati che verranno duplicati e inviati ai client.
replica:Replicate()
Cosa fa: Dice a Replica: "Questa replica è pubblica, mandala a tutti!".
Dietro le quinte: Prende i dati e li invia tramite RemoteEvent a tutti i client attualmente connessi che hanno finito di caricare. Inoltre la salva in una lista interna: se un giocatore entra 1 minuto dopo, il server gli spedirà in automatico questa replica senza che tu debba fare niente.
replica:Destroy()
Cosa fa: Termina il ciclo vitale della replica.
Dietro le quinte: Cancella la tabella dal server, rimuove la replica dalla memoria e invia un segnale di rimozione a tutti i client. Sul client, questa chiamata scatena in automatico il Maid.

Spiegazione riga per riga — Lato Client

ServerReplication.Client.OnNew("GameEvent", function(Replica) ... end)
Cosa fa: È il punto di ascolto. Dice al client: "Appena ricevi dal server una replica che ha Token 'GameEvent', esegui questa funzione".
Come lavora: Ti passa come argomento l'oggetto Replica popolato con i Data e i Tags inviati dal server. Si attiva sia per gli eventi che partono mentre stai giocando, sia per quelli già attivi quando sei appena entrato.
Replica.Data.Name / Replica.Data.Duration
Cosa fa: Legge i valori dalla tabella replicata. Sul client questa tabella è considerata in sola lettura (non puoi fare Replica.Data.Name = "Altro" sul client, solo il server può modificarla con :Set()).
Replica.Maid:Add(function() ... end)
Cosa fa: È il sistema di pulizia automatica (garbage collection).
Come lavora: Qualsiasi funzione o istanza che inserisci dentro Maid:Add() verrà eseguita o distrutta all'istante esatto in cui il server chiama replica:Destroy(). È perfetto per togliere la UI a schermo o fermare effetti visivi quando l'evento finisce.
ServerReplication.Client.RequestData()
Cosa fa: È l'interruttore che avvia la comunicazione.
Perché è obbligatoria: All'avvio del gioco, il client aspetta di aver caricato la mappa e gli script. Con questa riga manda un segnale al server dicendo: "Server, io sono pronto, registrami e mandami tutte le repliche che hai!". Senza questa chiamata, il server ti ignora e OnNew non scatterà mai.

2 Replica Privata (a un singolo giocatore)

Per mandare una replica solo al singolo giocatore (dati privati come monete, gemme, inventario), la differenza chiave è una sola: invece di replica:Replicate(), usi replica:Subscribe(player). Ecco l'esempio più corto possibile.

SERVER PlayerDataServer.luau

--!strict
local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local ServerReplication = require(ReplicatedStorage.Packages.ServerReplication)

local Token = ServerReplication.Server.Token("PlayerData")

Players.PlayerAdded:Connect(function(player)
	-- 1. Crea la replica taggata con l'UserId del player
	local replica = ServerReplication.Server.New({
		Token = Token,
		Tags = { UserId = player.UserId },
		Data = {
			Coins = 100,
			Gems = 10,
		},
	})

	-- 2. Appena il client di questo player è pronto, gliela inviamo SOLO a lui con :Subscribe()
	local conn: any
	conn = ServerReplication.Server.NewReadyPlayer:Connect(function(readyPlayer)
		if readyPlayer == player then
			conn:Disconnect()
			replica:Subscribe(player) -- 👈 Invia SOLO a questo player!
		end
	end)

	-- 3. Quando il player esce, distrugge la replica
	Players.PlayerRemoving:Connect(function(leavingPlayer)
		if leavingPlayer == player then
			replica:Destroy()
		end
	end)
end)

CLIENT PlayerDataClient.luau

--!strict
local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local ServerReplication = require(ReplicatedStorage.Packages.ServerReplication)

local LocalPlayer = Players.LocalPlayer

-- Ascolta l'arrivo dei tuoi dati
ServerReplication.Client.OnNew("PlayerData", function(replica)
	-- Controlla che sia la tua replica
	if replica.Tags.UserId ~= LocalPlayer.UserId then return end

	warn("✅ DATI RICEVUTI! Coins:", replica.Data.Coins, "| Gems:", replica.Data.Gems)

	-- Ascolta se il server ti aggiunge o toglie monete
	replica:OnSet({"Coins"}, function(newCoins: number)
		warn("💰 Coins aggiornati a:", newCoins)
	end)
end)

-- Avvisa il server che sei pronto
ServerReplication.Client.RequestData()
La differenza in sintesi:
➔ replica:Replicate() — La vedono tutti i player nel server (es. eventi globali, blocchi della mappa, round).
➔ replica:Subscribe(player) — La vede esclusivamente quel giocatore (es. monete, livello, impostazioni private). Gli altri player non sapranno nemmeno che esiste.

3 Networker (di Leif Stout)

Networker serve a scambiare dati tra Server e Client senza creare RemoteEvent a mano: colleghi direttamente le funzioni del tuo Service.

SERVER MyService.luau

Espone le funzioni che il client può chiamare.

--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Networker = require(ReplicatedStorage.Packages.networker)

local MyService = {}

function MyService:Init()
	-- Inizializza il networker per questo service
	self.networker = Networker.server.new("MyService", self, {
		self.GiveCoins, -- Funzioni autorizzate che il client può chiamare
	})
end

function MyService:GiveCoins(player: Player, amount: number)
	print(player.Name, "ha chiesto", amount, "monete")
	return true -- Può anche restituire un valore al client!
end

-- Se il server vuole mandare qualcosa al client:
function MyService:NotifyPlayer(player: Player, msg: string)
	self.networker:fire(player, "ShowNotice", msg)
	-- self.networker:fireAll("ShowNotice", msg) -- Per tutti
end

return MyService

CLIENT MyClient.luau

Si aggancia allo stesso nome ("MyService") e chiama le funzioni del server.

--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Networker = require(ReplicatedStorage.Packages.networker)

local MyClient = {}

function MyClient:Init()
	local networker = Networker.client.new("MyService", self)

	-- 1. Invia dati al server (stile RemoteEvent)
	networker:fire("GiveCoins", 50)

	-- 2. Invia e aspetta la risposta dal server (stile RemoteFunction)
	task.spawn(function()
		local success = networker:fetch("GiveCoins", 100)
		print("Risposta dal server:", success)
	end)
end

-- Funzione chiamata dal server se fa self.networker:fire(player, "ShowNotice", msg)
function MyClient:ShowNotice(msg: string)
	print("Messaggio dal server:", msg)
end

return MyClient
In sintesi:
➔ :fire("NomeFunzione", ...) — Spara l'evento e non aspetta risposta (come FireServer / FireClient).
➔ :fetch("NomeFunzione", ...) — Chiama la funzione sul server e aspetta il valore di ritorno (come InvokeServer).

Guida Funzioni Sift

Riferimento rapido per le funzioni di Array e Dictionary

1. Funzioni con Callback (function(...))

Funzione Cosa fa la callback Restituisce Esempio pratico
Array.filter Ritorna true per tenere l'elemento Nuovo array filtrato Array.filter({5, 12, 20}, function(v) return v >= 10 end)👉 {12, 20}
Dictionary.filter Ritorna true per tenere la coppia (v, k) Nuovo dizionario filtrato Dictionary.filter({A=10, B=2}, function(v) return v > 5 end)👉 {A = 10}
Array.map Ritorna il valore trasformato Nuovo array modificato Array.map({1, 2, 3}, function(v) return v * 10 end)👉 {10, 20, 30}
Dictionary.map Ritorna il valore modificato Nuovo dizionario modificato Dictionary.map({X=5}, function(v) return v + 1 end)👉 {X = 6}
Array.sort Ritorna a > b (decresc.) o a < b (cresc.) Nuovo array ordinato Array.sort({3, 1, 4}, function(a, b) return a > b end)👉 {4, 3, 1}
Array.some Ritorna true se almeno uno matcha boolean (true/false) Array.some({2, 5, 8}, function(v) return v > 6 end)👉 true
Dictionary.some Ritorna true se almeno una coppia matcha boolean (true/false) Dictionary.some({A=1, B=9}, function(v) return v >= 5 end)👉 true
Array.every Ritorna true solo se tutti matchano boolean (true/false) Array.every({10, 20, 5}, function(v) return v >= 10 end)👉 false
Dictionary.every Ritorna true solo se tutti matchano boolean (true/false) Dictionary.every({A=10, B=20}, function(v) return v >= 10 end)👉 true
Array.count Ritorna true per conteggiare l'elemento number (totale match) Array.count({1, 5, 8, 9}, function(v) return v > 4 end)👉 3
Dictionary.count Ritorna true per conteggiare la coppia number (totale match) Dictionary.count({A=1, B=5}, function(v) return v > 2 end)👉 1
Array.find Ritorna true quando trova l'elemento Elemento trovato + indice Array.find({10, 25, 30}, function(v) return v > 20 end)👉 25, 2
Dictionary.update Prende il vecchio valore e ritorna il nuovo Nuovo dizionario aggiornato Dictionary.update({Kills=2}, "Kills", function(old) return old + 1 end)👉 {Kills = 3}
Array.reduce Aggrega i valori (acc, value) Valore finale aggregato Array.reduce({10, 20, 30}, function(acc, v) return acc + v end, 0)👉 60

2. Funzioni Normali più Utilizzate (senza callback)

Funzione Cosa fa Restituisce Esempio pratico
Dictionary.merge Unisce due o più dizionari (l'ultimo sovrascrive) Nuovo dizionario fuso Dictionary.merge({A = 1}, {B = 2, A = 99})👉 {A = 99, B = 2}
Dictionary.mergeDeep Unisce dizionari anche nelle sotto-tabelle Nuovo dizionario profondo Dictionary.mergeDeep({Cfg={A=1}}, {Cfg={B=2}})👉 {Cfg = {A=1, B=2}}
Dictionary.set Assegna o cambia una singola chiave Nuovo dizionario Dictionary.set({Coins = 10}, "Coins", 50)👉 {Coins = 50}
Dictionary.removeKey Rimuove una chiave specifica Nuovo dizionario Dictionary.removeKey({Coins = 10, Temp = 1}, "Temp")👉 {Coins = 10}
Sift.None Valore speciale per cancellare chiavi con merge Segnale di cancellazione Dictionary.merge({Coins=10, Exp=5}, {Exp = Sift.None})👉 {Coins = 10}
Dictionary.keys Estrae tutte le chiavi in un array Array di stringhe/chiavi Dictionary.keys({Coins = 10, Level = 1})👉 {"Coins", "Level"}
Dictionary.values Estrae tutti i valori in un array Array di valori Dictionary.values({Coins = 10, Level = 1})👉 {10, 1}
Dictionary.copyDeep Clona ricorsivamente la tabella staccando ogni puntatore Tabella identica e isolata local safeCopy = Dictionary.copyDeep(originalTable)
Array.push Inserisce elementi alla fine dell'array Nuovo array esteso Array.push({"Wood", "Stone"}, "Iron")👉 {"Wood", "Stone", "Iron"}
Array.concat Unisce due o più array in fila Nuovo array combinato Array.concat({1, 2}, {3, 4})👉 {1, 2, 3, 4}
Array.slice Estrae una porzione dell'array (start, end) Sotto-array estratto Array.slice({"A", "B", "C", "D"}, 2, 3)👉 {"B", "C"}

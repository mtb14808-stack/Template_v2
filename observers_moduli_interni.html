observeTagtag, callback, ancestors?

Osserva tutte le istanze che hanno un certo Tag di CollectionService, comprese quelle già esistenti al momento dell'avvio.

Come funziona dentro: tiene una tabella instances che segna ogni istanza come "__inflight__" (in fase di avvio), "__dead__" (senza tag/callback attiva) oppure con la funzione di cleanup salvata. Si collega a GetInstanceAddedSignal e GetInstanceRemovedSignal del tag, più a AncestryChanged per ogni istanza, cosicché se esce dagli ancestors consentiti (es. fuori da workspace) viene trattata come rimossa anche se il tag resta. La callback gira dentro xpcall per non far crashare l'observer in caso di errore. 
local stop = Observers.observeTag("Coin", function(coin)
	print("Tag aggiunto:", coin)
	return function()
		print("Tag rimosso o istanza distrutta")
	end
end, { workspace })
observePropertyinstance, propertyName, callback, guard?

Osserva una proprietà (es. Health, Name) e reagisce ogni volta che cambia, oltre a scattare subito una volta all'avvio.

Come funziona dentro: si collega a GetPropertyChangedSignal. Ogni cambiamento incrementa un contatore changeCounter usato come "numero di versione": se il valore cambia di nuovo prima che la callback precedente finisca di eseguire il suo cleanup, quella vecchia esecuzione viene scartata invece di sovrascrivere lo stato per errore (evita race condition). Il guard opzionale permette di ignorare valori che non ti interessano. 
local stop = Observers.observeProperty(humanoid, "Health", function(hp)
	print("Vita:", hp)
	return function() --[[ cleanup prima del prossimo cambio ]] end
end)
observePlayercallback

Osserva ogni giocatore presente e futuro nel server.

Come funziona dentro: si collega a Players.PlayerAdded e Players.PlayerRemoving, e all'avvio scorre subito Players:GetPlayers() per i giocatori già connessi. Salva il cleanup di ogni player in una tabella cleanupsPerPlayer, così quando esce viene richiamato automaticamente solo il suo. 
local stop = Observers.observePlayer(function(player)
	print("Entrato:", player.Name)
	return function() print("Uscito:", player.Name) end
end)
observeCharactercallback

Osserva il Character (avatar) di ogni giocatore ogni volta che spawna.

Come funziona dentro: è costruito sopra observePlayer — per ogni player si mette in ascolto di CharacterAdded e gestisce anche il Character già presente al momento dell'osservazione. Il cleanup del personaggio scatta quando AncestryChanged segnala che il Character non ha più un genitore (cioè è stato tolto dal gioco, es. alla morte). 
local stop = Observers.observeCharacter(function(player, char)
	print(player.Name, "spawnato")
	return function() print("Character rimosso") end
end)
observeChildreninstance, callback, guard?

Osserva solo i figli diretti (non nipoti) di un'istanza.

Come funziona dentro: si collega a ChildAdded / ChildRemoved e, all'avvio, scorre GetChildren(). Il guard opzionale filtra quali figli far passare (es. solo le Part). Tiene una mappa figlio → cleanup per richiamare solo quello giusto alla rimozione. 
local stop = Observers.observeChildren(workspace, function(child)
	print("Figlio aggiunto:", child.Name)
	return function() print("Figlio rimosso") end
end)
observeDescendantsinstance, callback, guard?

Come observeChildren, ma osserva tutti i discendenti, non solo i figli diretti.

Come funziona dentro: stessa logica di observeChildren ma con DescendantAdded / DescendantRemoving e GetDescendants() all'avvio. Utile quando serve reagire a oggetti annidati a qualsiasi profondità (es. tutte le Part dentro un Model complesso). 
local stop = Observers.observeDescendants(workspace.Model, function(desc)
	print("Discendente:", desc:GetFullName())
	return function() end
end, function(d) return d:IsA("BasePart") end)
observeAttributeinstance, attributeName, callback, guard?

Osserva un singolo attributo specifico, scattando solo quando il valore non è nil.

Come funziona dentro: filtra internamente AttributeChanged per il nome scelto e richiama il cleanup precedente prima di ogni nuovo valore. Se il nuovo valore è nil (attributo rimosso), semplicemente non richiama più la callback — il cleanup della versione precedente resta l'ultima parola. 
local stop = Observers.observeAttribute(kart, "Stunned", function(v)
	print("Stun:", v)
	return function() print("Stun rimosso") end
end)
observeAllAttributesinstance, callback, guard?

Come observeAttribute, ma osserva tutti gli attributi dell'istanza invece di uno solo.

Come funziona dentro: si collega all'evento globale AttributeChanged (che scatta per qualunque attributo), tiene una tabella di cleanup per nome di attributo e all'avvio scorre GetAttributes() per inizializzare quelli già presenti. Il guard riceve sia nome che valore, utile per filtrare per tipo (es. solo numeri). 
local stop = Observers.observeAllAttributes(part, function(name, value)
	print(name, "=", value)
	return function() print(name, "rimosso") end
end)
